# 测试报告模板说明

此目录用于存放Word格式的测试报告模板。

> **隐私提示**：模板文件仅在本地处理，不会上传到任何服务器。

## 如何使用

1. 将你的Word模板文件（.docx格式）放入此目录
2. 在模板中使用 `{{变量名}}` 格式添加占位符
3. 运行生成脚本时通过 `--template` 参数指定模板路径

## 模板变量

在模板中可以使用以下变量：

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `{{report_title}}` | 报告标题 | 系统功能测试报告 |
| `{{report_date}}` | 报告日期 | 2026-04-09 |
| `{{test_period}}` | 测试周期 | 2026-04-01 至 2026-04-08 |
| `{{tester}}` | 测试人员 | 张三 |
| `{{project_name}}` | 项目名称 | 订单管理系统 |
| `{{total_cases}}` | 总用例数 | 150 |
| `{{passed_cases}}` | 通过用例数 | 142 |
| `{{failed_cases}}` | 失败用例数 | 5 |
| `{{blocked_cases}}` | 阻塞用例数 | 3 |
| `{{pass_rate}}` | 通过率 | 94.67% |

## 报告结构建议

建议在模板中包含以下一级标题，便于自动生成内容：

1. **测试概述** - 测试目的、范围、环境
2. **测试执行情况** - 用例执行、进度、资源
3. **测试结果统计** - 通过率、缺陷统计、覆盖率
4. **缺陷分析** - 分布、严重级别、趋势
5. **测试结论与建议** - 质量评估、风险、改进建议
6. **附录** - 用例清单、详细数据

## 示例模板

你可以基于以下结构创建模板：

```
{{report_title}}

目录
（插入Word自动目录，生成后按 Ctrl+A 然后 F9 刷新）

1. 测试概述
   1.1 测试目的
   1.2 测试范围
   1.3 测试环境

2. 测试执行情况
   2.1 测试用例执行情况
   2.2 测试进度

3. 测试结果统计
   总用例数：{{total_cases}}
   通过：{{passed_cases}}
   失败：{{failed_cases}}
   阻塞：{{blocked_cases}}
   通过率：{{pass_rate}}

4. 缺陷分析

5. 测试结论与建议

6. 附录

测试人员：{{tester}}
报告日期：{{report_date}}
```

## 注意事项

- 模板必须是 `.docx` 格式
- 变量占位符使用双大括号 `{{变量名}}`
- 建议在模板中预设好样式（标题、正文、表格等）
- 目录使用Word的自动目录功能，生成后需要手动刷新
