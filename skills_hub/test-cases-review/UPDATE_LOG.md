### 2. 新增功能

#### 2.1 测试用例设计方法覆盖检查

- **等价类划分检查**：有效等价类、无效等价类、空值、特殊字符
- **边界值分析检查**：最小值、最大值、边界附近值
- **场景法检查**：基本流、备选流（异常场景）
- **错误推测法检查**：重复提交、并发操作、大数据量

#### 2.2 完整性评审问题分级

| 级别 | 严重程度 | 判定标准 | 示例 |
|------|---------|---------|------|
| P0 | 严重 | 步骤/结果为空 | 测试步骤列无内容 |
| P1 | 一般 | 描述模糊 | 包含"正常"、"正确"等词 |
| P2 | 建议 | 设计方法覆盖不足 | 缺少边界值测试 |

#### 2.3 专项评审检查清单

- **测试步骤完整性检查**：是否为空、是否模糊、是否有编号
- **预期结果完整性检查**：是否为空、是否可验证、是否与步骤对应
- **测试设计方法覆盖检查**：等价类、边界值、场景法

#### 2.4 Excel标记规范

| 严重程度 | 背景颜色 | 说明 |
|---------|---------|------|
| 严重 | 🔴 红色（FF6B6B） | 步骤/结果为空 |
| 一般 | 🟠 橙色（FFA500） | 描述模糊 |
| 建议 | 🟡 黄色（FFFF00） | 可优化 |

### 3. 新增使用方法

#### 方式5：测试用例完整性分析

```
请对以下测试用例进行完整性分析，重点检查测试步骤和预期结果：
- 文件路径：[Excel文件路径]
- 分析标准：@templates/atc-testcase-standards.md

分析要求：
1. 检查测试步骤完整性（是否为空、是否模糊、是否有编号）
2. 检查预期结果完整性（是否为空、是否可验证、是否与步骤对应）
3. 检查测试用例设计方法覆盖（等价类、边界值、场景法）
4. 识别遗漏或需要补充的测试场景
5. 输出完整性分析报告
```

#### 方式6：生成带标记的Excel分析报告

```
请对以下测试用例文件生成带标记的Excel分析报告：
- 文件路径：[Excel文件路径]

要求：
1. 在原Excel中标记问题单元格（红色/橙色/黄色）
2. 添加批注说明具体问题
3. 生成汇总报告Excel
4. 生成详细分析报告（Markdown格式）
```

### 6. 使用建议

1. **定期评审**：建议每个迭代结束后进行完整性评审
2. **优先修复**：按照P0→P1→P2优先级逐步完善
3. **团队培训**：将测试设计方法（等价类、边界值、场景法）纳入团队培训
4. **工具集成**：可将完整性检查集成到CI/CD流程中
