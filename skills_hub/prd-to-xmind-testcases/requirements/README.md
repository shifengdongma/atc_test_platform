# 需求文档目录

将需要生成测试用例的**需求文档**放在此目录下，Skill 可根据你的指令读取并生成 XMind 测试用例大纲。

## 支持格式（需求文档）

- **PRD / 需求文档**：`.docx`（Word）、`.md`（Markdown）
- **PDF**：`.pdf`
- **纯文本**：`.txt`

## 生成的测试用例格式（XMind 导入）

- Skill 会输出 **Markdown (.md)** 文件。XMind **不支持 .txt 导入**，也不支持复制粘贴文本，请使用生成的 **.md** 文件。
- 导入方式：XMind → **文件** → **导入** → **Markdown** → 选择该 .md 文件。

## 使用方式

在对话中说例如：

- 「读取 requirements 里的需求文件，生成测试用例」
- 「根据 requirements 目录下的 PRD 生成思维导图测试用例」
- 「读取 [文件名].pdf 并生成测试用例」（若文件在本目录下，可只写文件名）

若未指定具体文件，Skill 会列出本目录下的文档供你选择后再生成。
