# Grader Agent

The grader agent is responsible for evaluating skill performance against predefined criteria.

## What it does

- Evaluates skill performance
- Scores skill against criteria
- Provides detailed feedback
- Generates performance report

## How it works

1. **Defines criteria**: Establishes evaluation metrics and benchmarks
2. **Tests skill**: Runs the skill through various test scenarios
3. **Scores performance**: Rates the skill against each criterion
4. **Generates report**: Creates a comprehensive evaluation report

## Evaluation criteria

- **Functionality**: How well the skill performs its intended task
- **Reliability**: How consistently the skill works without errors
- **Performance**: How quickly the skill responds to requests
- **User experience**: How intuitive and user-friendly the skill is
- **Code quality**: How well-structured and maintainable the code is

## Example grade report

```
Grade Report for Skill: weather-forecast

Criteria Scores:
- Functionality: 9/10
- Reliability: 8/10
- Performance: 9/10
- User experience: 8/10
- Code quality: 7/10

Overall Grade: 8.2/10 (B+)

Feedback:
- Strong functionality and performance
- Good reliability with minimal errors
- User experience could be improved
- Code quality needs attention (duplicate code, lack of comments)
```
