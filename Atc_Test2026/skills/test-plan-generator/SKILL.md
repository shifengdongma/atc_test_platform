# 测试方案生成器

根据多种输入源在本地自动生成格式化的Word测试方案文档。

## 功能概述

- **本地处理**：所有文件解析均在本地完成，数据不上传后台
- 支持输入：文字描述、Excel需求、Xmind思维导图、Word需求文档、原型设计图
- 基于Word模板生成测试方案
- 自动刷新目录、保持模板格式
- 默认输出到 `F:\下载` 目录

## 使用方法

### 1. 准备模板

将Word模板文件放入以下目录之一：
- **技能模板目录**：`.lingma/skills/test-plan-generator/templates/`
- **用户自定义目录**：用户指定的任意目录

### 2. 提供输入数据

支持以下输入方式（可组合使用），**所有文件均在本地解析，不会上传**：
- **文字描述**：直接提供功能需求、业务流程、测试范围等
- **Excel文件**：本地解析需求清单、功能点列表、测试要点
- **Xmind文件**：本地提取需求结构、功能模块划分、测试思路
- **Word文件**：本地读取需求规格说明书、产品文档
- **图片文件**：本地识别原型图、流程图（如提供）

### 3. 生成测试方案

运行生成脚本，指定模板和输入文件：

```bash
python .lingma/skills/test-plan-generator/scripts/generate_plan.py \
  --template templates/测试方案模板.docx \
  --output "F:\下载" \
  --input-data "功能需求描述" \
  --input-excel "需求清单.xlsx" \
  --input-xmind "功能结构.xmind" \
  --project-name "项目名称"
```

## 输入文件处理规则（本地解析）

> **隐私说明**：所有输入文件均在本地使用Python库解析，不会上传到任何服务器或后台。

### Excel文件（本地解析）
- 使用 `openpyxl` 库在本地读取Excel文件
- 自动识别需求清单、功能点列表
- 提取测试要点和验收标准
- 支持多工作表合并处理

### Xmind文件（本地解析）
- 使用 `xmindparser` 库在本地解析Xmind文件
- 提取功能模块结构和测试思路
- 支持多级主题嵌套解析
- 保留备注和标签信息

### Word文件（本地解析）
- 使用 `python-docx` 库在本地读取Word文件
- 提取需求规格说明内容
- 保留原有格式和层级结构
- 支持内容追加或替换

### 图片文件（本地处理）
- 使用 `PIL/Pillow` 库在本地处理图片
- 支持原型图、流程图插入
- 图片仅在本地嵌入文档，不上传

## 输出规范

- **默认输出目录**：`F:\下载`
- **文件名格式**：`{项目名}_测试方案_{日期}.docx`
- **目录自动刷新**：生成后自动更新目录页
- **格式保持**：完全遵循模板格式

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 模板变量未替换 | 检查占位符格式是否为 `{{变量名}}` |
| 目录未刷新 | 手动在Word中按 `Ctrl+A` 后 `F9` 刷新 |
| Excel格式错乱 | 确保Excel中合并单元格已取消 |
| Xmind解析失败 | 确保文件为.xmind格式（非.xmind.zip） |
| 图片无法插入 | 确保图片格式为jpg/png，路径正确 |
