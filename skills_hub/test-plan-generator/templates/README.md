# 测试方案模板说明

此目录用于存放Word格式的测试方案模板。

> **隐私提示**：模板文件仅在本地处理，不会上传到任何服务器。

## 如何使用

1. 将你的Word模板文件（.docx格式）放入此目录
2. 在模板中使用 `{{变量名}}` 格式添加占位符
3. 运行生成脚本时通过 `--template` 参数指定模板路径

## 模板变量

在模板中可以使用以下变量：

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `{{plan_title}}` | 方案标题 | 系统功能测试方案 |
| `{{plan_date}}` | 方案日期 | 2026-04-09 |
| `{{project_name}}` | 项目名称 | 订单管理系统 |
| `{{version}}` | 版本号 | V1.0 |
| `{{author}}` | 编写人 | 张三 |
| `{{reviewer}}` | 审核人 | 李四 |
| `{{approve_date}}` | 批准日期 | 2026-04-10 |
| `{{total_requirements}}` | 需求总数 | 50 |
| `{{total_modules}}` | 功能模块数 | 8 |
| `{{test_types}}` | 测试类型 | 功能、性能、安全 |
| `{{estimated_duration}}` | 预计工期 | 30人天 |

## 测试方案结构建议

建议在模板中包含以下一级标题，便于自动生成内容：

1. **引言** - 文档目的、适用范围、参考资料
2. **测试目标与范围** - 测试目标、测试范围、测试边界
3. **测试策略** - 测试类型、测试方法、测试工具
4. **测试环境** - 硬件环境、软件环境、网络环境
5. **测试用例设计** - 用例设计方法、用例优先级、覆盖标准
6. **测试执行计划** - 测试阶段、时间安排、人员分配
7. **风险评估与应对** - 风险识别、风险等级、应对措施
8. **交付物清单** - 测试文档、测试数据、测试报告

## 示例模板结构

你可以基于以下结构创建模板：

```
{{plan_title}}

文档信息：
- 项目名称：{{project_name}}
- 版本号：{{version}}
- 编写人：{{author}}
- 审核人：{{reviewer}}
- 日期：{{plan_date}}

目录
（插入Word自动目录，生成后按 Ctrl+A 然后 F9 刷新）

1. 引言
   1.1 文档目的
   1.2 适用范围
   1.3 参考资料

2. 测试目标与范围
   2.1 测试目标
   2.2 测试范围
   2.3 不在测试范围内

3. 测试策略
   3.1 测试类型
       - 功能测试
       - 接口测试
       - 性能测试
   3.2 测试方法
   3.3 测试工具

4. 测试环境
   4.1 硬件环境
   4.2 软件环境
   4.3 网络环境

5. 测试用例设计
   5.1 用例设计方法
   5.2 用例优先级定义
   5.3 覆盖标准

6. 测试执行计划
   6.1 测试阶段划分
   6.2 时间安排
   6.3 人员分配

7. 风险评估与应对
   7.1 风险识别
   7.2 风险等级
   7.3 应对措施

8. 交付物清单
   8.1 测试计划
   8.2 测试用例
   8.3 测试报告

附录
- 需求清单
- 功能模块列表
```

## 注意事项

- 模板必须是 `.docx` 格式
- 变量占位符使用双大括号 `{{变量名}}`
- 建议在模板中预设好样式（标题、正文、表格等）
- 目录使用Word的自动目录功能，生成后需要手动刷新
- 可根据实际项目需要调整章节结构
