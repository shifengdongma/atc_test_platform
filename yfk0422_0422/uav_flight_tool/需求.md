# UAV 飞行数据工具整合需求

## 一、背景

现有两个独立项目：
- **uav_emitter**：支持自定义 JSON 轨迹文件的场景化发送
- **utm_随机模拟飞行数据**：支持随机生成飞行计划并物理仿真，可进行 3000 架批量性能测试

## 二、目标

将两个项目整合为一个统一项目，放置于 `无人机飞行数据自动化工具yfk0422` 目录下。

## 三、功能需求

### 3.1 核心功能

| 需求 | 说明 |
|------|------|
| 发送自定义轨迹 | 支持加载预定义的 JSON 场景文件并按配置发送 |
| 3000 批量性能测试 | 支持多线程并发仿真，维持 3000 架无人机稳定发送 |
| 航空器名称按指定格式生成 | 支持模板化名称生成（如 `UAV_{seq:05d}`），可后续实现预留接口 |
| 统一运行入口 | 一个 `main.py` 脚本入口运行所有模式 |
| 配置驱动 | 通过 `config.yaml` 配置文件或命令行参数切换模式和控制行为 |
| WebUI/GUI 预留 | 在配置中预留 webui/gui 相关配置节，方便后续开发接入 |

### 3.2 运行模式

1. **场景模式** (`scene`)：加载自定义 JSON 轨迹文件发送（原 uav_emitter 功能）
2. **仿真模式** (`simulation`)：随机生成飞行计划并物理仿真发送（原 main_multi.py 功能）
3. **压力测试模式** (`stress_test`)：3000 架批量性能测试，仿真与发送解耦（原 main_multi2.py 功能）
