# Agent 测试方案（AI版本）

## 一、测试概述

本测试方案针对基于 llmwiki 开发的 Agent 进行全面测试，涵盖 **RAG（检索增强生成）**、**Chat调用Agent**、**文档固定** 三大核心功能，并与 **Dify**、**Cherry Studio** 等主流知识库系统进行对比测试，验证 Agent 的性能、准确性和可靠性。

---

## 二、测试目标

| 目标类别 | 具体目标 |
|---------|---------|
| **功能验证** | 验证 RAG 文档解析、向量检索、知识问答功能正确性 |
| **性能评估** | 测试响应时间、吞吐量、资源消耗 |
| **兼容性对比** | 与 Dify、Cherry Studio 进行功能和性能对比 |
| **一致性验证** | 验证接口调用与本地执行结果的一致性 |
| **可靠性测试** | 测试异常处理、边界条件、并发场景 |

### 5.1 测试步骤

1. **文档准备阶段**
   - 收集测试文档（PDF/MD/TXT等格式）
   - 上传至各测试平台（llmwiki Agent、Dify、Cherry Studio）
   - 记录文档ID和上传时间

2. **问题生成阶段**
   - 基于文档内容自动生成测试问题
   - 人工审核和补充问题
   - 标注标准答案

3. **测试执行阶段**
   - 调用 llmwiki Agent 本地接口
   - 调用 llmwiki Agent 远程API
   - 记录响应时间和结果

4. **对比执行阶段**
   - 调用 Dify API 执行相同查询
   - 调用 Cherry Studio API 执行相同查询
   - 记录各平台响应结果

5. **结果分析阶段**
   - 计算准确率、召回率、相似度
   - 分析性能指标
   - 识别问题和差异

6. **报告生成阶段**
   - 生成测试报告
   - 汇总问题和建议

### 7.2 测试代码示例

```python
import requests
import json
from difflib import SequenceMatcher

class AgentTest:
    def __init__(self):
        self.local_url = "http://localhost:8000/chat"
        self.api_url = "https://api.example.com/agent/chat"
        self.dify_url = "https://api.dify.ai/v1/chat-messages"
        self.cherry_url = "https://api.cherrystudio.com/api/chat"
    
    def test_rag_single(self, question, document_id):
        """测试单个问题在不同平台的表现"""
        # 本地调用
        local_result = self._call_local(question, document_id)
        
        # 接口调用
        api_result = self._call_api(question, document_id)
        
        # Dify调用
        dify_result = self._call_dify(question, document_id)
        
        # Cherry调用
        cherry_result = self._call_cherry(question, document_id)
        
        # 计算相似度
        similarities = {
            "local_api": self._calculate_similarity(local_result, api_result),
            "local_dify": self._calculate_similarity(local_result, dify_result),
            "local_cherry": self._calculate_similarity(local_result, cherry_result)
        }
        
        return {
            "question": question,
            "local": local_result,
            "api": api_result,
            "dify": dify_result,
            "cherry": cherry_result,
            "similarities": similarities
        }
    
    def _call_local(self, question, document_id):
        """调用本地Agent"""
        response = requests.post(
            self.local_url,
            json={"question": question, "document_id": document_id}
        )
        return response.json()["answer"]
    
    def _call_api(self, question, document_id):
        """调用远程API"""
        response = requests.post(
            self.api_url,
            json={"question": question, "document_id": document_id},
            headers={"Authorization": "Bearer YOUR_TOKEN"}
        )
        return response.json()["answer"]
    
    def _call_dify(self, question, document_id):
        """调用Dify API"""
        response = requests.post(
            self.dify_url,
            json={"question": question, "document_id": document_id},
            headers={"Authorization": "Bearer DIFY_TOKEN"}
        )
        return response.json()["answer"]
    
    def _call_cherry(self, question, document_id):
        """调用Cherry Studio API"""
        response = requests.post(
            self.cherry_url,
            json={"question": question, "document_id": document_id},
            headers={"Authorization": "Bearer CHERRY_TOKEN"}
        )
        return response.json()["answer"]
    
    def _calculate_similarity(self, text1, text2):
        """计算文本相似度"""
        return SequenceMatcher(None, text1, text2).ratio()
```

### 10.2 测试指标定义

| 指标 | 定义 | 计算公式 |
|-----|------|---------|
| **准确率** | 回答正确的比例 | 正确数/总数 × 100% |
| **召回率** | 检索到相关文档的比例 | 相关文档数/应检索到的文档数 × 100% |
| **精确率** | 检索结果中相关文档的比例 | 相关文档数/检索到的文档数 × 100% |
| **相似度** | 两个文本的相似程度 | 基于编辑距离的相似度计算 |
| **QPS** | 每秒处理请求数 | 总请求数/总时间 |
| **响应时间** | 请求到响应的时间 | 记录每个请求的耗时 |
