# Docker 容器调试命令

## 重新构建并部署（修复 Dameng -70089 + MySQL Access denied + pymysql 导入）
```bash
cd /opt/atc_test_platfrom
docker compose -f docker/docker-compose.yml build --no-cache
docker compose -f docker/docker-compose.yml down
docker volume rm atc_test_platfrom_utm-database
docker compose -f docker/docker-compose.yml up -d
```

## 查看启动日志
```bash
docker logs utm-simulator 2>&1 | grep -E "MySQL|Mysql|达梦|DmDb|dm|pymysql|mysql_db"
```

## 查看完整启动诊断日志（含 pymysql + MySQL 连接测试）
```bash
docker logs utm-simulator 2>&1 | head -80
```

## 进入容器验证
```bash
docker exec -it utm-simulator bash
```

### 验证 pymysql 安装与 mysqldbclient 导入
```bash
python3 -c "
import pymysql
print('pymysql version:', pymysql.__version__)
import sys
sys.path.insert(0, '/app/atc_api_autotest/api_tools')
from mysqldbclient import MysqlDbClient
print('MysqlDbClient import OK')
"
```

### 验证 MySQL 连接（使用环境变量中的配置）
```bash
python3 -c "
import os, pymysql
host = os.environ.get('UTM_MYSQL_HOST', '127.0.0.1')
port = int(os.environ.get('UTM_MYSQL_PORT', '3306'))
user = os.environ.get('UTM_MYSQL_USER', 'root')
password = os.environ.get('UTM_MYSQL_PASSWORD', '')
database = os.environ.get('UTM_MYSQL_DB', 'utm_simulator')
print(f'连接目标: {host}:{port}/{database} as {user}')
try:
    conn = pymysql.connect(host=host, port=port, user=user,
                           password=password, database=database,
                           ssl={}, connect_timeout=10)
    print('MySQL OK')
    conn.close()
except Exception as e:
    print(f'MySQL 连接失败: {e}')
"
```

### 手动测试 MySQL（指定 IP 和密码）
```bash
python3 -c "
```

## 排查 MySQL "Access denied" 错误

### 1. 检查容器实际使用的 MySQL 配置
```bash
docker exec utm-simulator python3 -c "
import sys; sys.path.insert(0, '/app/common')
from config import load_mysql_config
cfg = load_mysql_config()
print(f'configured={cfg.configured}')
print(f'host={cfg.host}')
print(f'port={cfg.port}')
print(f'user={cfg.user}')
print(f'database={cfg.database}')
print(f'password={"***" if cfg.password else "(empty)"}')
"
```

### 2. 查看容器 IP（MySQL 用户可能需要授权此 IP）
```bash
docker exec utm-simulator hostname -I
```

### 3. 从容器测试到 MySQL 的网络连通性
```bash
docker exec utm-simulator timeout 5 bash -c "echo >/dev/tcp/10.165.32.147/3306 && echo 'TCP 可达' || echo 'TCP 不可达'"
```

### 4. MySQL 服务端授权（在 MySQL 服务器上执行）
```sql
-- 允许 utm 用户从任意 IP 连接（%）
CREATE USER IF NOT EXISTS 'utm'@'%' IDENTIFIED BY '<MySQL密码>';
GRANT ALL PRIVILEGES ON utm_simulator.* TO 'utm'@'%';
FLUSH PRIVILEGES;
-- 验证
SELECT host, user FROM mysql.user WHERE user='utm';
```
