# Docker 容器调试命令

## 重新构建并部署（修复 Dameng -70089 + MySQL Access denied）
```bash
cd /opt/atc_test_platfrom
docker compose -f docker/docker-compose.yml build --no-cache
docker compose -f docker/docker-compose.yml down
docker volume rm atc_test_platfrom_utm-database
docker compose -f docker/docker-compose.yml up -d
```

## 查看启动日志
```bash
docker logs utm-simulator 2>&1 | grep -E "MySQL|Mysql|达梦|DmDb|dm"
```

## 进入容器验证
```bash
docker exec -it utm-simulator bash
```
