# 项目 Skills 目录

本目录用于存放项目级别的 AI Skills（技能），供各 AI 助手调用。

## 目录结构

```
skills/
├── README.md           # 本文件
├── code-review/        # 代码审查技能
├── test-generation/    # 测试用例生成技能
├── doc-generation/     # 文档生成技能
└── <custom-skill>/     # 自定义技能
    ├── SKILL.md        # 技能描述文件
    └── prompt.md       # 提示词模板
```

## Skill 编写规范

每个 Skill 目录应包含：

1. **SKILL.md**: 技能说明、使用场景、输入输出定义
2. **prompt.md**: 完整的提示词模板
3. **examples/** (可选): 示例输入输出
