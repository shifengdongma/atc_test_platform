# 参考资料目录

本目录用于存放 API 文档、业务知识库等参考资料。

## 目录结构

```
references/
├── README.md              # 本文件
├── api_docs/              # API 文档
│   └── (放置接口文档)
├── domain_knowledge/      # 领域知识
│   └── (放置业务规则文档)
└── best_practices.md      # 最佳实践
```

## 使用说明

1. **API 文档**：放置接口契约、请求响应示例
2. **领域知识**：放置业务规则、状态机、流程说明
3. **最佳实践**：测试用例设计的通用最佳实践

## 添加新参考资料

1. 根据类型放入对应子目录
2. 使用清晰的文件命名（如 `repayment_api_v2.md`）
3. 在 SKILL.md 中添加引用链接
