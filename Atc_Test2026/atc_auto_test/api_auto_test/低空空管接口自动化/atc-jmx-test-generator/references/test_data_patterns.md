# 测试数据生成模式

## 概述

本文档描述低空空管系统接口测试用例中使用的测试数据生成规则和模式。

## 数据生成规则

### 起降场相关数据

#### 起降场名称

**规则：** `AUTO起降场 + 时间戳 + 随机字符`

**模板：**
```
AUTO起降场${__time(MMddHHmmss)}${__RandomString(1,ABCDEFGHJKLMN,)}${__RandomString(1,0123456789,)}
```

**示例：**
- `AUTO起降场0422203840A1`
- `AUTO起降场0422203841B2`

**说明：**
- 使用 `AUTO` 前缀便于测试后识别和清理
- 时间戳确保唯一性
- 随机字符增加多样性

#### 起降场编号

**规则：** `时间戳 + 2位随机大写字母`

**模板：**
```
${__time(MMddHH)}${__RandomString(2,ABCDEFGHJKLMNPQRSTUVWXYZ,)}
```

**示例：**
- `042220AB`
- `042220CD`

**说明：**
- 使用月日时分确保唯一性
- 排除易混淆字符（I, O, 0）

#### 起降场规模

**枚举值：**
- `HUB` - 起降枢纽
- `SITE` - 起降场
- `POINT` - 起降点
- `TEMP_POINT` - 临时起降点

**示例：**
- `121.132456`
- `121.132789`

#### 纬度

**规则：** `38.726 + 3位随机数字`

**模板：**
```
38.726${__RandomString(3,0123456789,)}
```

**范围：** 38.726000 ~ 38.726999

**示例：**

- `38.726456`

**说明：**
- 基于大连地区的坐标范围
- 确保生成的坐标在有效范围内

- `2042220001010123X`

## 测试数据使用建议

### 数据唯一性

1. **使用时间戳**：确保每次生成的数据唯一
2. **添加随机字符**：增加数据多样性
3. **使用 AUTO 前缀**：便于测试后识别和清理

### 数据清理

1. **查询测试数据**：使用关键字 `AUTO` 查询
2. **批量删除**：通过接口批量删除测试数据
3. **定时清理**：设置定时任务清理过期测试数据

### 数据验证

1. **格式验证**：确保生成的数据符合接口要求
2. **范围验证**：确保数值在有效范围内
3. **唯一性验证**：确保关键字段不重复
