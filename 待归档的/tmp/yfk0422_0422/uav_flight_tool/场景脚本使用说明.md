# 场景化飞行数据生成器 - 使用说明

## 一、简介

`scene_generator.py` 是一个独立的 Python 脚本，用于根据起始坐标、轨迹类型、速度和无人机ID，生成标准格式的 JSON 飞行数据文件。

支持生成以下轨迹类型：

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `straight_line` | 直线飞行 | 航向角、距离 |
| `polyline` | 折线飞行 | 航点列表 |
| `circle` | 圆形飞行 | 圆心、半径、方向 |
| `hover` | 定点盘旋 | 悬停位置、时长 |
| `ascent_descent` | 爬升后下降 | 目标高度、航向 |
| `figure8` | 8字形飞行 | 圆心、半径 |
| `spiral` | 螺旋飞行 | 起始/结束半径、圈数 |

## 二、运行方式

### 方式一：交互式模式（推荐新手）

```bash
cd uav_flight_tool/scripts
python scene_generator.py
# 或
python scene_generator.py --interactive
```

按提示逐步输入参数即可生成数据。

### 方式二：命令行模式

#### 直线飞行
```bash
python scene_generator.py \
  --type straight_line \
  --uid UAV_001 \
  --start-lon 120.7 \
  --start-lat 31.3 \
  --start-alt 100 \
  --speed 15 \
  --duration 300 \
  --heading 90 \
  --output straight.json
```

#### 圆形飞行
```bash
python scene_generator.py \
  --type circle \
  --uid UAV_002 \
  --center-lon 120.7 \
  --center-lat 31.3 \
  --center-alt 200 \
  --speed 15 \
  --duration 600 \
  --radius 500 \
  --output circle.json
```

#### 爬升后下降
```bash
python scene_generator.py \
  --type ascent_descent \
  --uid UAV_003 \
  --start-lon 120.7 \
  --start-lat 31.3 \
  --start-alt 50 \
  --speed 15 \
  --duration 600 \
  --target-alt 500 \
  --heading 90 \
  --output ascent.json
```

#### 螺旋飞行（爬升）
```bash
python scene_generator.py \
  --type spiral \
  --uid UAV_004 \
  --center-lon 120.7 \
  --center-lat 31.3 \
  --start-alt 100 \
  --speed 15 \
  --duration 600 \
  --start-radius 100 \
  --end-radius 1000 \
  --turns 3.0 \
  --output spiral.json
```

### 方式三：配置文件模式（批量生成）

```bash
python scene_generator.py --config scene_generator_config.yaml
```

配置文件格式见 `scene_generator_config.yaml` 示例。

## 三、参数说明

### 通用参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--type` / `-t` | str | 必填 | 轨迹类型，见上方类型表 |
| `--uid` / `-u` | str | 自动生成 | 无人机唯一标识 |
| `--start-lon` | float | 120.7 | 起始经度 |
| `--start-lat` | float | 31.3 | 起始纬度 |
| `--start-alt` | float | 100 | 起始高度（米） |
| `--speed` / `-s` | float | 15 | 飞行速度（m/s） |
| `--duration` / `-d` | int | 300 | 飞行时长（秒） |
| `--interval` | int | 1000 | 数据点间隔（毫秒） |
| `--output` / `-o` | str | 自动生成 | 输出 JSON 文件路径 |

### 各类型专用参数

#### straight_line（直线飞行）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--heading` | float | 90 | 航向角（0=正北, 90=正东, 180=正南, 270=正西） |

#### polyline（折线飞行）
交互式模式下支持输入多个航点，配置文件模式下使用 `waypoints` 数组：

```yaml
waypoints:
  - lon: 120.7050
    lat: 31.3150
    alt: 150
  - lon: 120.7100
    lat: 31.3100
    alt: 100
```

#### circle（圆形飞行）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--center-lon` | float | start-lon | 圆心经度 |
| `--center-lat` | float | start-lat | 圆心纬度 |
| `--center-alt` | float | start-alt | 圆心高度 |
| `--radius` / `-r` | float | 500 | 圆半径（米） |
| `--clockwise` | bool | True | 顺时针飞行 |
| `--counter-clockwise` | flag | - | 逆时针飞行（与 --clockwise 互斥） |

#### hover（定点盘旋）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--start-lon` | float | 120.7 | 盘旋点经度 |
| `--start-lat` | float | 31.3 | 盘旋点纬度 |
| `--start-alt` | float | 100 | 盘旋点高度 |

#### ascent_descent（爬升后下降）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--target-alt` | float | 500 | 目标高度（米） |
| `--heading` | float | 90 | 航向角 |

#### figure8（8字形飞行）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--center-lon` | float | start-lon | 圆心经度 |
| `--center-lat` | float | start-lat | 圆心纬度 |
| `--center-alt` | float | start-alt | 圆心高度 |
| `--radius` / `-r` | float | 500 | 8字半径（米） |

#### spiral（螺旋飞行）
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--start-radius` | float | 100 | 起始半径（米） |
| `--end-radius` | float | 1000 | 结束半径（米） |
| `--turns` | float | 3.0 | 旋转圈数 |
| `--climb` | bool | True | 螺旋爬升 |
| `--descend` | flag | - | 螺旋下降（与 --climb 互斥） |

## 四、配置文件说明

配置文件采用 YAML 格式，支持批量生成多个场景：

```yaml
output: "batch_scene.json"

scenes:
  - type: straight_line
    uid: "UAV_001"
    start_lon: 120.7000
    start_lat: 31.3100
    start_alt: 100
    speed: 15
    duration: 300
    heading: 90
    interval_ms: 1000
```

每个场景独立配置，最终所有数据合并到一个 JSON 文件中。

## 六、使用示例

### 快速生成一条直线数据
```bash
python scene_generator.py -t straight_line -u UAV_TEST -o test.json
```

### 生成 10 分钟圆形飞行数据
```bash
python scene_generator.py -t circle -u UAV_CIRCLE -d 600 -r 800 -o circle_10min.json
```

### 批量生成多种场景
```bash
python scene_generator.py --config scene_generator_config.yaml
```

## 七、注意事项

1. **经纬度坐标**：使用 WGS-84 坐标系（度）
2. **航向角定义**：0=正北，90=正东，180=正南，270=正西
3. **时间戳**：自动生成当前时间戳，数据点间隔默认 1000ms
4. **高度单位**：米（m）
5. **速度单位**：米/秒（m/s）
6. 生成的 JSON 文件可直接用于 `uav_flight_tool` 的场景模式发送，也可用于 `ha_multi_sender.py` 高可用多点多组发送

# 高可用多点多组发送器 - 使用说明

## 一、简介

`ha_multi_sender.py` 是独立的高可用多点多组发送脚本，参考 `utm_moc52_ha` 多进程高可用设计。

核心能力：
- **多点**：同时向多个 Kafka/Redis 集群发送数据
- **多组**：每组独立进程运行，互不干扰
- **alive 模式**：数据耗尽后自动循环发送
- **trace 消费**：每个端点独立消费 `uav_runtime_trace`
- **数据源灵活**：支持 JSON 场景文件 和 实时仿真 两种模式

## 二、运行方式

### 配置文件模式（推荐）

```bash
cd uav_flight_tool/scripts
python ha_multi_sender.py --config ha_multi_sender_config.yaml
```

### Dry-run 模式（仅验证配置）

```bash
python ha_multi_sender.py --config ha_multi_sender_config.yaml --dry-run
```

## 三、配置说明

配置文件为 YAML 格式，核心结构：

```yaml
endpoints:
  - name: "cluster_a_scene"
    kafka_url: "10.165.32.24:29092"
    redis_host: "10.165.32.24"
    redis_port: 26379
    redis_password: "xxx"
    redis_db: 0
    topic: "uav_runtime_data"
    trace_topic: "uav_runtime_trace"
    data_source_type: "scene_file"   # scene_file | simulation
    scene_file: "../scenes/xxx.json"
    interval_ms: 1000
    alive_mode: true
    consume_trace: true

  - name: "cluster_b_sim"
    kafka_url: "10.165.32.25:29092"
    redis_host: "10.165.32.25"
    redis_port: 26379
    redis_password: "yyy"
    data_source_type: "simulation"
    drone_count: 60
    interval_ms: 1000
    alive_mode: true
    consume_trace: true
```

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `name` | str | 端点名称标识 |
| `kafka_url` | str | Kafka 集群地址 |
| `redis_host` | str | Redis 主机地址 |
| `redis_port` | int | Redis 端口 |
| `redis_password` | str | Redis 密码（可选） |
| `topic` | str | Kafka 发送目标 topic |
| `trace_topic` | str | trace 消费 topic |
| `data_source_type` | str | `scene_file` 或 `simulation` |
| `scene_file` | str | 场景文件路径（scene_file 模式必填） |
| `drone_count` | int | 仿真机数（simulation 模式） |
| `interval_ms` | int | 发送间隔（毫秒） |
| `alive_mode` | bool | `true`=数据耗尽后循环；`false`=发送完停止 |
| `consume_trace` | bool | 是否独立消费 `uav_runtime_trace` |
| `num_workers` | int | 仿真模式工作线程数（默认 15） |
| `drone_count` | int | 仿真模式总活跃无人机数（默认 3000） |
| `timestamp_offset_ms` | int | 时间戳偏移量（毫秒，默认 -1000） |
| `enable_worker_log` | bool | 是否打印 Worker 详细日志 |

## 四、工作流程

1. 主进程读取 YAML 配置，解析所有端点
2. 为每个端点启动独立子进程
3. 子进程内：
   - 连接对应 Kafka Producer 和 Redis
   - 初始化数据源（场景文件 或 仿真器）
   - 启动发送线程：按 interval_ms 周期发送数据
   - 启动 trace 消费线程：消费并记录预测数据
4. 主进程监控所有子进程状态，Ctrl+C 统一停止

## 五、典型场景

### 场景1：双集群场景发送
向 Kafka/Redis 集群 A 和集群 B 同时发送相同/不同的场景数据：

```yaml
endpoints:
  - name: "cluster_a"
    kafka_url: "10.165.32.24:29092"
    redis_host: "10.165.32.24"
    data_source_type: "scene_file"
    scene_file: "../scenes/scene_a.json"

  - name: "cluster_b"
    kafka_url: "10.165.32.25:29092"
    redis_host: "10.165.32.25"
    data_source_type: "scene_file"
    scene_file: "../scenes/scene_b.json"
```

### 场景2：双集群仿真发送
向两个集群同时发送实时仿真数据：

```yaml
endpoints:
  - name: "cluster_a_sim"
    kafka_url: "10.165.32.24:29092"
    redis_host: "10.165.32.24"
    data_source_type: "simulation"
    drone_count: 60

  - name: "cluster_b_sim"
    kafka_url: "10.165.32.25:29092"
    redis_host: "10.165.32.25"
    data_source_type: "simulation"
    drone_count: 60
```

### 场景3：混合模式（场景 + 仿真）
集群 A 发送场景文件，集群 B 发送仿真数据：

```yaml
endpoints:
  - name: "cluster_a_scene"
    kafka_url: "10.165.32.24:29092"
    data_source_type: "scene_file"
    scene_file: "../scenes/demo.json"

  - name: "cluster_b_sim"
    kafka_url: "10.165.32.25:29092"
    data_source_type: "simulation"
    drone_count: 100
```

## 六、注意事项

1. **group_id 隔离**：每个端点的 Kafka Consumer 使用独立 group_id，确保各端点都能收到全部 trace 消息
2. **进程隔离**：每个端点独立进程，单个端点异常不会影响其他端点
3. **场景文件路径**：支持相对路径（相对于脚本目录）和绝对路径
4. **alive_mode**：
   - `true`：场景文件数据耗尽后自动从头循环，仿真模式持续运行
   - `false`：场景文件数据耗尽后该端点自动退出
5. 生成的场景 JSON 可用 `scene_generator.py` 提前生成
