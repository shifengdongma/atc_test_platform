## 一、系统概述

### 1.1 平台简介

低空空管自动化测试平台是一个完整的 ATC/UTM 测试解决方案，核心能力：

- **无人机群仿真**：模拟数百至数千架无人机沿航线飞行，生成逼真的飞行计划与实时遥测
- **数据注入**：通过 Redis/Kafka 向 ATC Dashboard 注入仿真数据，Dashboard 对数据来源无感知
- **API 自动化测试**：覆盖 IOMP 运维平台和 ATC 业务系统的接口测试
- **高可用测试**：双集群故障切换验证、数据一致性检查、大规模压力测试
- **Web 可视化控制台**：5 种仿真模式、数据生成面板、实时地图监控

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **飞行计划（Flight Plan）** | 无人机从起飞到降落的完整航线规划，存储在 Redis `BIZ_DATA:UAV_ROUTE` Hash 中 |
| **实时遥测（Telemetry）** | 无人机每秒上报的位置/速度/高度/状态数据，通过 Kafka `uav_runtime_data` 发送 |
| **轨迹预测（Trace）** | 下游 UTM 引擎对无人机未来轨迹的预测结果，通过 Kafka `uav_runtime_trace` 回传 |
| **禁飞区（No-Fly Zone）** | 4D 空域限制区域（含时间窗），存储在 Redis `BIZ_DATA:AIRSPACE` |
| **动态仿真（Dynamic）** | 仿真引擎实时生成飞行计划和遥测，含真实动力学模型 |
| **预生成回放（Replay）** | 从预录制的 JSON 文件循环回放遥测数据 |

### 1.3 数据流总览

```
模拟器 → Redis (飞行计划) → ATC Dashboard 展示航线
模拟器 → Kafka (实时遥测) → ATC Dashboard 展示位置
模拟器 ← Kafka (轨迹预测) ← 下游 UTM 引擎
```

## 二、快速开始

### 2.1 环境要求

| 组件 | 要求 |
|------|------|
| Python | 3.11.15（Conda 环境 `utm`） |
| Conda | Anaconda3 / Miniconda3 |
| Redis | 推荐 4.5+，用于飞行计划和空域存储 |
| Kafka | 推荐 2.0+，用于遥测数据传输 |
| MySQL | 5.7+ / 8.0+，测试平台主数据库 |
| 操作系统 | Windows 10+ / Linux（Ubuntu 20.04+） |

### 2.2 安装步骤

```bash
# 1. 克隆仓库
git clone <repo-url>
cd atc_test_platfrom

# 2. 创建并激活 Conda 环境
conda create -n utm python=3.11.15
conda activate utm

# 3. 安装依赖
cd utm_simulator
pip install -r requirements.txt

# 4. 配置连接信息
# 编辑 utm_simulator/env.py，填写 Redis/Kafka 地址和密码
# 或启动 Web 控制台后在环境管理页配置

# 5. 配置 MySQL（如使用 Docker，通过环境变量注入）
# 设置环境变量: UTM_MYSQL_HOST, UTM_MYSQL_PORT, UTM_MYSQL_USER, UTM_MYSQL_PASSWORD, UTM_MYSQL_DB

# 6. 验证安装
python cli.py check    # 检查 Redis/Kafka 连通性
python cli.py status   # 查看 Redis 中数据量
```

### 2.3 启动 Web 控制台

```bash
# Windows PowerShell
.\start_web.ps1

# 或直接使用 CLI
python cli.py server

# 浏览器访问
# http://localhost:5000
```

### 2.4 Docker 快速部署

```bash
cd /opt/atc_test_platfrom

# 配置环境变量（编辑 docker/.env.example 或 docker-compose.yml）
# 首次构建并启动
docker compose -f docker/docker-compose.yml build --no-cache
docker compose -f docker/docker-compose.yml up -d

# 查看日志
docker logs -f utm-simulator

# 浏览器访问 http://<服务器IP>:5000
```

## 三、Web 可视化控制台

Web 控制台是平台的主要操作界面，提供仿真控制、数据生成、环境管理、日志查看等全部功能。

### 3.1 页面总览

启动后访问 `http://localhost:5000`，自动跳转到仿真执行页。

**双导航系统**：左侧导航栏 + 顶部导航栏，覆盖 9 个功能模块。

| 页面 | URL | 功能 |
|------|-----|------|
| 🎮 **仿真执行** | `/run` | 三栏合并布局：仿真参数配置 + 实时监控 + 地图可视化 |
| ⏰ **定时任务** | `/schedule` | 定时任务 CRUD + 执行历史查看 |
| 🔧 **数据生成** | `/generate` | 5 个 Tab：基础生成/单机场景/多机场景/批量预设/AI 生成 |
| 📂 **JSON 管理** | `/data` | JSON 数据文件浏览、搜索、CRUD、导入导出 |
| 🌐 **环境管理** | `/env` | 多套 Redis/Kafka 配置切换与管理 |
| 📊 **系统日志** | `/logs` | 4 个 Tab：监视目标/飞行计划/实时告警/全部日志 |

> 基础数据（`/basicdata`）、性能（`/performance`）、高可用（`/ha`）页面为占位页，功能开发中。

### 3.2 仿真执行页（`/run`）— 核心操作页

此页面集成了仿真参数配置、实时监控和地图三个功能区域。

**左侧 — 仿真参数配置**：
1. 选择**仿真模式**（动态仿真 / 预生成回放 / 场景文件 / Redis 计划插值）
2. 配置参数：
   - 无人机数量（1-5000）
   - 巡航速度（m/s）
   - 仿真中心点（经纬度）
   - 仿真半径（米）
3. 选择**环境配置**（从环境管理页预配置的连接信息中选择）
4. 点击 **▶ 启动仿真** 开始运行
5. 点击 **⏹ 停止仿真** 结束运行

**中间 — 实时监控面板**：
- 无人机数量趋势图（Chart.js 折线图，60 点滚动窗口）
- Kafka 消息吞吐量趋势图
- 运行时长计时器
- 错误率统计
- 运行日志（含类型过滤：INFO/WARNING/ERROR，支持暂停/导出）

**右侧 — 地图可视化**：
- Leaflet 交互式地图，高德瓦片（国内秒加载）
- 航线轨迹（彩色折线）
- 无人机实时位置（动态 Marker）
- 禁飞区/空域（半透明多边形图层）
- 图例切换
- WGS-84 原生坐标，无需转换

### 3.3 定时任务页（`/schedule`）

创建和管理自动化仿真任务：

1. **新建任务**：填写任务名称、Cron 表达式、仿真模式、参数
2. **编辑任务**：点击任务列表中的编辑按钮
3. **启停任务**：开关控制任务是否启用
4. **查看历史**：查看任务执行日志（开始时间、状态、消息）
5. **删除任务**：删除不再需要的任务

**Cron 表达式格式**（5 字段）：
```
分 时 日 月 星期
* * * * *    # 每分钟执行
*/5 * * * *  # 每 5 分钟执行
0 9 * * 1-5  # 工作日 9:00 执行
```

### 3.4 数据生成页（`/generate`）

5 个 Tab 对应不同生成模式：

| Tab | 功能 | 适用场景 |
|-----|------|---------|
| **基础生成** | 随机/网格/放射三种算法生成飞行数据 | 快速获得一批随机航线 |
| **单机场景** | 航线飞行/偏离航路/状态变更 | 单架无人机特定行为模拟 |
| **多机场景** | 平行飞行/碰撞预警/状态告警/偏离(高级) | 多机交互与告警场景 |
| **批量预设** | 11 个全国区域一键生成 | 批量生成覆盖全国的数据 |
| **AI 生成** | LLM 驱动的智能数据生成 | 自然语言描述生成场景 |

生成结果自动保存到 `data/mock/` 目录，并注册到数据库 `sim_json_files` 表。

### 3.5 JSON 管理页（`/data`）

管理所有 JSON 数据文件：

- **浏览**：分页显示所有文件，支持搜索和分类过滤
- **查看**：点击文件预览 JSON 内容
- **编辑**：在线编辑 JSON 内容并保存
- **删除**：删除不需要的文件
- **导入/导出**：与 `data/mock/` 目录双向同步
- **上传**：从本地上传 JSON 文件

### 3.6 环境管理页（`/env`）

管理多套 Redis/Kafka 连接配置：

- **新增环境**：填写名称、Redis IP/端口/密码、Kafka URL
- **编辑环境**：修改已有环境配置
- **激活环境**：设置某环境为当前使用（`is_active=true`）
- **删除环境**：移除环境配置
- **从 env.py 导入**：一键导入 `utm_simulator/env.py` 中的配置

> 环境配置保存在 MySQL `sim_env_config` 表中，Web 端和 CLI 端共享。

### 3.7 系统日志页（`/logs`）

4 个竖排 Tab 展示不同类型的实时日志：

| Tab | 数据来源 | 内容 |
|-----|---------|------|
| 🛸 **监视目标** | STOMP WebSocket `/flightTrack/SEAT0001` | 无人机实时位置/速度/高度/状态/分类详情 |
| 📋 **飞行计划** | REST API + Redis 回退 | 飞行计划统计（total/waiting/active/completed/rejected/cancelled） |
| ⚠️ **实时告警** | STOMP WebSocket `alarmStatistic` | 告警详情（编号/类别/等级/原因/时间） |
| 📜 **全部日志** | 合并以上 + Redis/DB/Kafka 监控 | 全部结构化日志条目 |

**操作功能**：
- 切换 Tab 查看不同日志类型
- 点击 UAV 卡片展开详情
- 告警卡片高亮显示严重等级
- 暂停/恢复日志滚动
- 导出为 JSON 或 CSV 文件
- 10 秒自动轮询刷新

## 四、仿真模式详解

### 4.1 五种模式对比

| 维度 | dynamic | replay | replay_once | scene | plan |
|------|---------|--------|-------------|-------|------|
| **中文名** | 动态仿真 | 预生成回放(循环) | 预生成回放(单次) | 场景文件注入 | Redis计划插值 |
| **数据来源** | Simulator引擎实时生成 | JSON文件循环读取 | JSON文件单次读取 | JSON按间隔发射 | Redis航段几何插值 |
| **物理模型** | ✅ 真实动力学 | ❌ 回放预记录 | ❌ 回放预记录 | ❌ 回放预记录 | ❌ 线性插值 |
| **禁飞区** | ✅ 动态生成 | ❌ | ❌ | ❌ | ❌ |
| **停止条件** | 手动停止 | 手动停止 | 数据耗尽自动停止 | 数据耗尽/手动停止 | 手动停止 |
| **适用场景** | 开发调试 | 长期稳定注入 | 精确单次回放+精度报告 | 特定场景复现 | 轻量注入 |

### 4.2 动态仿真（Dynamic）— 推荐开发调试

最完整的仿真模式，由 `SimulationManager` 管理 `Simulator` 引擎：

```
Simulator 工作流:
1. 初始化 → 创建指定数量 DroneAgent
2. 每步(1秒) →
   a. 生成/更新飞行计划 → 写入 Redis BIZ_DATA:UAV_ROUTE
   b. 动力学计算(加减速/爬升/降落) → 生成遥测
   c. 批量发送遥测 → Kafka uav_runtime_data
   d. 消费轨迹预测 → Kafka uav_runtime_trace
   e. 检测禁飞区侵入 → 记录日志
3. 新无人机补充 → 保持目标数量恒定
```

**DroneAgent 6 状态机**：
```
IDLE → TAKEOFF → CRUISE → HOVER → LANDING → FINISHED
                    ↑         |
                    └─────────┘
```

### 4.3 预生成回放（Replay）— 生产主力

循环读取预生成的 JSON 文件，适合长期稳定注入：

```bash
# 通过 Web 控制台选择 "预生成回放(循环)" 模式
# 或 CLI
python tools/run_kafka_alive.py --count 60 --data-file mock/kafka_data.json
```

### 4.4 预生成回放单次（Replay Once）

与 Replay 类似，但数据耗尽后自动停止，并输出轨迹精度报告：

- 数据耗尽 → 自动停止仿真
- 生成 HTML 轨迹精度报告（`trajectory_accuracy_report.html`）

### 4.5 场景文件注入（Scene）

按指定间隔从 JSON 场景文件发射遥测：

| 时间戳模式 | 说明 |
|-----------|------|
| `replace` | 将原始时间戳替换为当前时间 |
| `align` | 将第一条消息对齐到当前时间，后续保持偏移 |
| `preserve` | 保持原始时间戳不变 |

### 4.6 Redis 计划插值（Plan）— 轻量模式

从 Redis `BIZ_DATA:UAV_ROUTE` 读取现有飞行计划航段，线性插值生成遥测：

- ✅ 无需仿真引擎，无需预生成文件
- ✅ 直接对接已申报的飞行计划
- ❌ 匀速直线插值，无真实动力学

## 五、数据生成指南

### 5.1 基础生成（Web 控制台 /generate → 基础生成 Tab）

三种生成算法：

| 算法 | 原理 | 适用场景 |
|------|------|---------|
| **随机** | 在指定区域内随机生成起降点和航线 | 通用测试数据 |
| **网格** | 按网格排列生成平行航线 | 密度测试、平行飞行 |
| **放射** | 从中心点向外放射状生成航线 | 空域覆盖测试 |

**输出文件**：
- `data/mock/redis_route.json` — 飞行计划（Redis 格式）
- `data/mock/kafka_data.json` — 实时遥测（Kafka 格式）

### 5.2 单机场景（/generate → 单机场景 Tab）

| 场景 | 说明 |
|------|------|
| **航线飞行** | 指定一条航线，生成无人机沿航线飞行的遥测数据 |
| **偏离航路** | 生成偏离预定航线的告警场景 |
| **状态变更** | 模拟无人机运行状态变化（正常→故障→恢复等） |

### 5.3 多机场景（/generate → 多机场景 Tab）

| 场景 | 说明 |
|------|------|
| **平行飞行** | 多架无人机平行编队飞行 |
| **偏离(高级)** | 指定偏离比例和角度的批量偏离场景 |
| **碰撞预警** | 两架无人机接近触发碰撞预警 |
| **状态告警** | 批量无人机状态异常告警 |

### 5.4 批量预设（/generate → 批量预设 Tab）

11 个全国预定义区域，一键生成：

- 北京、上海、深圳、成都、苏州、杭州、南京、武汉等
- 每个区域预设中心经纬度、半径、禁飞区

### 5.5 命令行生成

```bash
cd utm_simulator

# 基础生成（100 架无人机，仿真区域苏州金鸡湖附近）
python tools/create_data.py --count 100

# 单机场景
python tools/create_data_scene.py --mode deviation

# 综合场景
python tools/create_data_scenes.py parallel --count 50
python tools/create_data_scenes.py collision
python tools/create_data_scenes.py status --count 20
python tools/create_data_scenes.py batch
```

## 十一、定时任务

### 11.1 概述

定时任务系统基于 Cron 表达式，每 30 秒检查一次，自动启动仿真任务。

### 11.2 创建定时任务

**方式一：Web 控制台（推荐）**

访问 `/schedule` 页面：
1. 点击「新建任务」
2. 填写：
   - **任务名称**：描述性名称（如"每天9点_100架动态仿真"）
   - **Cron 表达式**：执行时间规则
   - **仿真模式**：dynamic / replay / plan / scene
   - **仿真参数**：JSON 格式（无人机数量、速度、中心点等）
3. 保存后自动启用

**方式二：直接操作数据库**

```sql
INSERT INTO sim_scheduled_tasks (name, cron_expr, sim_mode, sim_params, enabled)
VALUES (
    '每5分钟_Mock注入',
    '*/5 * * * *',
    'replay',
    '{"data_file": "kafka_data.json", "count": 60}',
    1
);
```

### 11.3 Cron 表达式参考

| 表达式 | 含义 |
|--------|------|
| `* * * * *` | 每分钟 |
| `*/5 * * * *` | 每 5 分钟 |
| `0 * * * *` | 每小时整点 |
| `0 9 * * 1-5` | 工作日 9:00 |
| `0 0,12 * * *` | 每天 0:00 和 12:00 |
| `0 8 * * 1` | 每周一 8:00 |

### 11.4 查看执行历史

在 `/schedule` 页面点击任务行，展开执行历史：
- 开始时间
- 结束时间
- 执行状态（运行中/成功/失败）
- 错误消息

### 13.3 常见问题

#### 地图加载不出来

- 确认浏览器可访问外网（高德瓦片 CDN）
- 检查浏览器开发者工具 → Network 面板
- 系统已内置 CartoDB/OSM 备选瓦片

#### Redis/Kafka 连接失败

- 确认 `env.py` 或 `config.json` 中地址和密码正确
- 通过 Web 控制台环境管理页直接测试连接
- 检查网络防火墙

#### MySQL 连接失败

- 见 `docs/命令手册.md` 完整排查流程
- Docker 环境检查 `UTM_MYSQL_*` 环境变量
- 确认 pymysql 版本为 1.x（`pip show pymysql`）

#### 仿真运行但没有数据

- 检查 Redis：`python cli.py status`
- 检查 Kafka：`python tools/kafka_read_latest.py`
- 查看 Web 控制台运行日志（含错误详情）

#### dmPython 导入失败

- 达梦数据库驱动需单独安装，仅影响数据库相关工具
- 不影响模拟器核心功能和 Web 控制台
